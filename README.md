## กิจกรรมวันนี้
1. Git คืออะไร = ระบบควบคุมเวอร์ชันของไฟล์ (Version Control System: VCS)
2. การทำงานของเว็บไซต์ทำงานอย่างไร = ผู้ใช้พิมพ์ URL เช่น [Link](https://www.dek-d.com/) ในเว็บเบราว์เซอร์
3. เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร = "เว็บไซต์" เน้นการให้ข้อมูล (Static Content) รับชมเพียงอย่างเดียว ส่วน "เว็บแอปพลิเคชัน" เน้นการปฏิสัมพันธ์ (Interactive) และการทำงานซับซ้อน
4.ให้สร้างคู่มือการใช้งาน Github = ขั้นตอนที่ 1: เลือก New repository ตั้งชื่อโปรเจกต์ในช่อง Repository name เลือกสถานะ Public (สาธารณะ) หรือ Private (ส่วนตัว) ติ๊กเลือก Add a README file แล้วกด Create repository
ขั้นตอนที่ 2: การติดตั้งและตั้งค่า Git ในเครื่องคอมพิวเตอร์ ดาวน์โหลดและติดตั้ง Git จาก git-scm.com เปิด Terminal (Mac/Linux) หรือ Git Bash (Windows) แล้วตั้งค่าชื่อและอีเมล
ขั้นตอนที่ 3: คำสั่ง Git และ GitHub ที่ใช้บ่อย
Clone (คัดลอกโปรเจกต์จาก GitHub ลงเครื่อง)
